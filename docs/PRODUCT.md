# Travel Memory

## 产品定位

Travel Memory 不是旅游攻略，不是旅游相册，也不是 AI 游记。

Travel Memory 的目标是：

帮助用户多年以后，
仍然能够找回一次旅行中的细节和回忆。

产品核心：

保存记忆，而不是保存照片。

---

## 用户痛点

几年以后：

我知道去过东京。

但是：

- 忘了吃过哪家店
- 忘了为什么拍这张照片
- 忘了当时发生了什么
- 忘了当天去了哪些地方

照片还在。

记忆消失了。

Travel Memory 希望解决这个问题。

---

## 产品原则

任何一次记录：

不能超过30秒。

用户负责体验旅行。

系统负责整理旅行。

不要要求用户写长篇游记。

## 开发原则

优先保证：

简单

稳定

快速

不要为了技术而增加复杂度。

所有新增功能必须回答：

它是否帮助用户更容易回忆一次旅行？

如果不是，则不开发。

---

## 禁止事项

第一版和第二版：

不要：

排行榜

点赞

评论

攻略

AI 聊天

短视频

直播

推荐算法

## 产品愿景

多年以后。

打开 Travel Memory。

用户可以重新体验一次旅行。

而不是重新浏览一次相册。
