# Travel Memory 产品状态

Travel Memory 保存真实发生过的旅行记忆，帮助用户多年以后重新体验一段旅行，而不只是浏览照片或记录流水账。

## 已完成 V1

- Trip：创建、查看和删除旅行。
- Trip 修改：旅行编辑前端页面已完成。
- Memory：新增、编辑、删除、图片上传、原话、时间、地点和坐标。
- Timeline：按 Day 浏览、搜索和收藏记忆。
- Journey：按 Day 和 Stop 回放旅行。
- Map 基础空间视图：显示有坐标的记忆点，不包含真实地图 SDK 或导航。

## 已完成 V1.1

- 图片 EXIF 时间和 GPS 解析。
- 浏览器当前位置，以及 WGS84 到 GCJ-02 转换。
- 高德逆地理编码和地点名称候选推荐；用户确认后采用推荐地点名称。
- Docker Compose 与阿里云 ECS 部署。
- Nginx Basic Auth 临时访问保护、安全 Nginx 覆盖和 `/healthz`。
- MySQL 与 uploads 本地备份脚本。
- 旅行封面管理：可从本旅行已有的 Memory 照片中设置或取消显式封面；未设置时自动使用第一张照片。暂不支持独立上传或裁切封面。

产品坚持照片和用户原话优先。Journey 用于重新体验旅行，不负责生成或改写故事。
