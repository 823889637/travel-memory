## V1.2 本地开发完成，待验收

- 单趟旅行自动回顾页
- 每日代表照片、旅行摘要、常出现地点和收藏片段
- Trip 同行者名单与 Memory 逐条关联
- 同行者页面将当前 `app_user` 作为“我”置顶展示，其他同行人由 Trip 名单维护
- 相关记忆按用户选择后查询：“我”对应本旅行全部 Memory，其他同行人对应其关联 Memory

- 同行者不等同于注册用户，不提供邀请、共同编辑或旅行访问权限
- 旅行内 5 项统一导航，以及 Timeline 收藏筛选替代独立收藏回看页
